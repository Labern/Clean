# Checkout blueprint: the code

The live Focus checkout (17 Nov 2026), saved as the template for every app's buy flow. The spec and the reasons are in
CHECKOUT-BLUEPRINT.md. Source of truth: Labern/paradoxica-hub, `sites/paradoxica.uk/focus/checkout/` and `api/`.

- `index.html`: the checkout page (left: what you're buying; right: Stripe's Payment + Express Checkout Elements).
  The publishable key is a placeholder here: put the app's own `pk_…` in `STRIPE_PK`. Prices come from the app's
  pricing.json (the `pricing:tiers` block is generated by bin/focus-pricing in the hub).
- `api/stripe.php`: makes the Checkout Session, reports status, takes Stripe's signed webhook. Secret keys live beside
  htdocs (~/stripe/secret.key, ~/stripe/webhook.secret), never in code.
- `api/feedback.php`: in-app feedback to help@paradoxica.co.uk, subject "APPNAME …", Reply-To the account's email.
- Installed on a server with the hub's `bin/api-install` (run by Claude, never by Labern).
