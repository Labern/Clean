Once.

You type your details once. Then never again — on every site, including ones you've never been to. Signups, logins, checkouts, address forms.

→Reads any form by what each box means — no site list, no per-site setup.
→Fills on sight. Only empty boxes, never ones you've changed, never hidden traps.
→Two emails: tap ⇄ to switch, and that site remembers which one you use there — so logins get the right one.
→Your details never leave your device. No server, no account, no tracking.

  2. Bookmark this page: Share → Add Bookmark → name it Once → Save.
  3. Open Bookmarks → Edit → tap Once → clear the address and paste.
  4. On any form: tap the address bar, type once, tap the bookmark. Done.

Tap it again on the same page to switch to your other email.

  1. Download Once and unzip it.

  3. Load unpacked → pick the unzipped once-extension folder.
  4. Reload this page. Your details pass straight into the extension.
