1 Sample Basics

This sample exists only to test the reader. It has ordinary paragraphs that wrap over several lines so the extractor has to join them back together, including a hyphen-ated word and some inline_code() in the middle of a sentence, plus emphasis and bold.

A second paragraph follows the first. It should stay separate from it, and it should also be long enough to wrap onto at least two lines of the narrow page so joining is exercised again.

1.1 Monospace code

The block below is set in a monospace face and has nested indentation and a blank line.

#include <vector>

int total(const std::vector<int>& v)
{
    int sum = 0;
    for (int x : v) {
        sum += x;        // add each element
    }
    return sum;
}

Text after the block continues here and should be a normal paragraph again, long enough to wrap around once or twice.
