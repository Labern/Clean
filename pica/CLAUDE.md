# PICA — a screenwriting instrument

A screenplay editor whose screen **is** the printed page. Imports a Final Draft PDF
(text-layer) and reproduces it **identically** — then makes it fully editable with the
complete Final Draft typing grammar. Live at `https://labern.github.io/Clean/pica/`.

## The play
`index.html` renders every wrapped line as an absolutely-positioned div at its true
pt coordinates on true-size pages — screen, print, and source PDF are one layout.
The pure engine (`/*PICA-ENGINE-START*/ … /*PICA-ENGINE-END*/` inside index.html)
does everything spatial: PDF line assembly, element classification (by x-column +
content), self-calibrating wrap widths (hard-break fallback per element), and a
Final Draft-faithful paginator — sentence-boundary splits, (MORE)/(CONT'D)
regeneration, slugline retraction, per-element `spaceBefore` overrides captured at
import. The UI treats contenteditable as a caret only: every `beforeinput` is
intercepted and applied to the model, never the DOM.

## THE CONTRACT — never break it
`node tests/run.mjs` must print **100.00%** (5,907/5,907 lines of Tenet identical
across 148 pages) before any engine change ships. Fixtures are pre-extracted in
`tests/fixtures/` (gitignored — copyrighted source); if absent, run.mjs re-downloads
and re-extracts (needs `npm i pdfjs-dist` inside tests/).

## Rules
- **Single self-contained index.html.** No build step, no framework. Only external
  refs: Google Fonts (Courier Prime) and pdfjs-dist from jsDelivr, lazy-loaded only
  when importing a PDF.
- **Storage: documents + snapshots live in IndexedDB** (`pica` db, `kv` store, keys
  `doc.<id>` / `snap.<id>`); the index and prefs stay in localStorage (`pica.index`,
  `pica.ui`). Never localStorage for bodies — WebKit's ~5MB quota silently broke
  saves (the "1-page blank" bug). Index metadata writes synchronously, withdrawn if
  the body fails to persist; a failed load never fabricates a blank; pagehide keeps
  a one-slot emergency mirror that becomes a snapshot on next boot. Additive-only,
  never wiped; snapshots ring-buffer 5 deep; drafts live INSIDE the doc (`doc.drafts`).
- **Engine changes**: edit inside the markers, run tests, keep 100%. The tests
  extract the engine from index.html itself — there is no second copy.
- Grammar map lives in the app (`?` overlay). Tab cycles → menu when options run
  out; Enter on empty → menu; ⌘1–8 direct; int./ext. auto-detects; SmartType feeds
  from the script itself.

## The element grammar is Final Draft's, verbatim — do not "improve" it
`FOLLOW` is FD12's own `ReturnKey=` attribute, read out of
`/Applications/Final Draft 12.app/Contents/Resources/Data/Templates/Script/Screenplay.fdxt`
(every `.fdx` carries the same `<ElementSettings>` block). Confirmed against the official
FD11 manual and the current FD KB — all three agree:

| element | Enter → | Tab → |
|---|---|---|
| Scene Heading | Action | Action (after walking the slug's sub-fields) |
| Action | Action | Character |
| Character | Dialogue | Parenthetical — **Transition if the cue is blank** |
| Parenthetical | Dialogue | Dialogue |
| Dialogue | Action | Parenthetical |
| Transition | Scene Heading | Scene Heading |
| Shot | Action | Character *(inferred — undocumented in every source)* |

Key facts that cost real research, so they are not re-litigated:
- **Enter is data-driven and user-configurable in FD; Tab is hardcoded** — `<Behavior>` has
  only `PaginateAs`, `ReturnKey`, `Shortcut`, `WinShortcut`. There is no TabKey anywhere.
- **Tab is one deterministic jump, never a cycle.** An earlier build cycled through all 8
  types; that is not FD and felt wrong. On a blank paragraph Tab *converts* it; at the end
  of a written one it *starts the next*.
- **Enter on a blank paragraph opens the element popup** (choose by number, first letter or
  arrows) — FD manual, p.323.
- **Slug sub-field walk:** in a Scene Heading, Tab adds `". "` then offers locations, adds
  the time separator then offers times, and only then moves on to Action.
- FD numbers elements 1–7 with **General on ⌘0** (8/9 are Cast List / New Act, not modelled).
- SmartType seeds (extensions, scene intros, times, transitions) are FD's shipped defaults;
  characters and locations come from the script itself. "Auto-guess next character" offers
  the *other* speaker in a two-hander.

## PICA.app — the native ⌘-Tab build (`mac/`)
`./mac/build.sh [--install]` → `mac/build/PICA.app`. A WKWebView shell around the *same*
`index.html` (copied in verbatim at build time — never forked). Real Dock tile, real
⌘-Tab slot, real menu bar; ~2.3 MB; icon is generated by `makeicon.swift`.

Two things here were paid for in blood — do not undo them:
- **It serves the app over a private `pica://` scheme, not `file://`.** That gives the page
  a stable origin, which is what makes `localStorage` persist across launches. Verified by
  writing on one run and reading it back on the next. Scripts must never be lost.
- **Never hand file bytes to JS as a base64 literal.** `evaluateJavaScript` silently drops
  a call carrying a screenplay-sized string (~384 KB) — no error, no exception, nothing
  runs. Native opens *stage* the bytes in the scheme handler's inbox and call
  `PICA_API.importUrl('/__inbox/<id>')`, which the page fetches.

The app bundles Courier Prime and pdf.js, so **PDF import works with no network**. The web
build falls back to Google Fonts and the jsDelivr CDN; `--font-family` puts
`"Courier Prime Local"` first precisely so the web fallback still works when it 404s.

`mac/smoketest.swift` verifies the built bundle headlessly (activation policy `.prohibited`
— no window, no focus theft): engine present, API exposed, localStorage on `pica://`, fonts
from the bundle, a non-PDF rejected cleanly, and a real 148-page offline import.
Run it after any change to the shell or the page:
```bash
cd mac && ./build.sh && swiftc -O smoketest.swift -o build/smoketest && ./build/smoketest
```

## Deploy (gh-pages worktree ritual)
```bash
cd ~/Desktop/Clean
git worktree add /tmp/ghp gh-pages
mkdir -p /tmp/ghp/pica && cp pica/index.html /tmp/ghp/pica/
cp -R pica/fonts /tmp/ghp/pica/          # so the web build needs no Google Fonts either
cd /tmp/ghp && git add -A && git commit -m "Deploy pica to Pages at /Clean/pica/" && git push
cd - && git worktree remove /tmp/ghp
```
