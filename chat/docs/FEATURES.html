CHAT

A native macOS client for WhatsApp — the real thing, in your own window. Reference · one page
Why it exists: so you never pick up your phone while you're working on the Mac. Every trade-off follows from that. A message that fails to reach you sends you back to your phone, so notification delivery outranks every other feature — the app holds a power assertion so macOS can't quietly suspend it in the background, ⌘W hides the window instead of severing the connection, and if macOS has blocked notifications it says so loudly rather than going silent. App ▸ Check Notifications Work… proves it end to end.

Focus mode — how to use it

  1. Press ⌘⇧F. That's it — nothing to set up first.
  2. The chat list collapses to only what wants you right now: anything unread, plus the conversation you're currently in. Anything you've pinned inside WhatsApp stays too, as do your ⌘1–⌘9 slots if you've set any.
  3. Everything else vanishes from the list. It updates live — a chat that goes unread reappears on its own.
  4. Press ⌘⇧F again to bring the full list back.
It only hides — it never changes anything. Nothing is archived, muted, marked read or altered on WhatsApp; the rows are hidden in this window and nowhere else, and your phone is untouched. If nothing is unread and no chat is open there is nothing to narrow down, so the list simply stays as it is rather than going blank. Pair it with companion mode ⌘⇧E to get one conversation, floating, beside your work.

The window

Companion mode⌘⇧E
Shrinks to a small panel floating above your work, showing just the open conversation — sidebar and nav rail collapsed away. Resize it freely; it remembers its own size, separate from the full window.
Always on top⌥⌘P
Keep the window above everything without shrinking it.
Fade when inactive
Goes gently translucent when it isn't the focused window, so it can sit beside what you're doing.
Menu-bar glance
Unread count in the menu bar; click it to summon or dismiss. The Dock tile carries the same badge.
Summon from anywhere⌃⌥⌘W
Global — works from any app, whether the window is hidden or buried.

Messages

Real macOS notifications
Proper banners with sound, whether or not the window is open.
Reply from the notification
Type into the banner and it sends — you never switch app. It checks the message box holds exactly what you typed before sending, and refuses (and tells you) if anything looks off.
Quick slots⌘1–9
Optional: Chats ▸ Pin This Chat ⌘⇧P puts the open chat on the next free number, then that key jumps straight to it. Matched by chat name, so re-pin if one gets renamed.
Quiet hours
Optional, off by default: silence notifications between chosen hours.
Voice notes, files, downloads
Microphone, attachments and saving media all work; downloads go to Downloads and never overwrite.

How it looks

Four themes⌘⌥T
Stock untouched · Midnight a quiet dark · PARADOX terminal teal-and-violet · MONOGRAPH black-and-white editorial. Cycles with one keystroke.
Any font you have
View ▸ Font for a curated few, or Choose… to pick any installed font — the panel sets the size at the same time.
Message text size⌘⌥ + −
Scales the words in the conversation only. Separate from ⌘ + −, which zooms the whole interface.
Names & list text
View ▸ Names & List Text — sizes contact names, previews and timestamps in the chat list, independently of the conversation.
Space between messages
View ▸ Space Between Messages — Snug through Wide, for how much air sits between one message and the next.

Peace and quiet

Distractions gone
Status, Channels, Communities, Media, Meta AI and the promo nags are hidden out of the box. Each is a tick in View if you want it back.
Focus mode⌘⇧F
Collapses the list to unread chats plus the one you're reading. No setup — see the panel above.
Privacy blur⌘⇧B
Blurs message text and chat names until you point at them — for screen sharing, or someone reading over your shoulder.
Your session is safe
It's the real WhatsApp Web, linked exactly as a browser links it. No protocol tricks, so nothing here risks your account. Links friends send open in your browser, not in here.
